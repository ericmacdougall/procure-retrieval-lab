# What the actual experiment teaches

The baseline matters. On the fixed, clarified registry questions, sparse BM25 already scored mean nDCG@10 of 0.9797066. Development selected a sparse-heavy mixture. Its held-out score was 0.9860221, a paired improvement of 0.0063156 with a query-bootstrap 95% interval from 0.0006806 to 0.0127154. This supports the preregistered quality rule for this finite benchmark. It does not establish a useful production improvement: related contract families recur, and clarified generated queries make identity lookup easier than open-ended user questions. Query resampling understates uncertainty associated with changing the registry or query-generation process.

Adding a learned component did not guarantee a better retriever. Dense retrieval scored 0.9098592, reciprocal-rank fusion 0.9555911, and the local cross-encoder reranker 0.9365676. The reranker's paired difference from BM25 was -0.0431390, with a 95% interval wholly below zero. These losing arms remain in the published evidence. There was no post-opening retune or promotion of a better-looking secondary configuration.

Answerability creates a second decision. At development-selected thresholds the final mixture caught 47 of 60 constructed no-answer cases, but also abstained on 59 of 354 answerable cases. The deterministic tool policy caught 57 of 60 no-answer cases and retained 333 of 354 answerable questions, while ranking quality was lower at 0.9562851. Answerable coverage is not answer correctness. There was no evaluated answer generator, and abstention precision depends on the artificial no-answer prevalence. A routing script is not proof of secure authorization, production isolation or an autonomous tool-using model.

Small evaluations encourage overconfidence. Searching 22 configurations on twelve questions selected a configuration with a perfect observed score and a degenerate [1,1] bootstrap interval. Its score on 280 fresh answerable questions was 0.9851209. The gap combines selection and changes in query composition; it is not a causal estimate of selection bias alone. Resampling twelve observed successes cannot create an unseen failure. A binomial interval is only a separate intuition for fixed binary trials, not a valid interval for selected nDCG.

Source identity is part of evaluation. Procurement registries contain repeated award versions and distinct contracts with nearly identical titles. Single-gold labels can mark a valid answer wrong or give redundant copies too much credit. This lab repaired labels globally before final selection, qualified questions consistently, dropped ambiguous description prefixes with counts, and collapsed only conservative equivalent fact groups. Those repairs improve validity while changing the task toward easier, explicit registry lookup; both effects must be disclosed.

Reproduction has levels. The public raw snapshot and data-only model judgments explain where the questions came from. The freeze binds the exact experiment and strict ranking contracts reject missing, duplicate or nonfinite outputs. Cached reruns reproduce calculations. Fresh model reruns depend on exact revisions, runtime and cache provenance. None of these establishes service response time, load capacity, cash savings or generalization to future buyers.

For the full numerical tables, paired intervals, error slices and limitations, read `REPORT.md` and the archived per-question outputs. For the chronology and commands, read `RUNLOG.md`. The lesson practice should ask learners to explain the weak gain, losing reranker, abstention tradeoff and duplicate-source labeling problem using these observed artifacts.
